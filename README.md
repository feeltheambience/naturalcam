# NaturalCam — ручная камера без ИИ-обработки

Нативное Android-приложение (Kotlin + Camera2 + Jetpack Compose) для съёмки
«естественных» фото: ручные ISO/выдержка/фокус/ББ, экспокоррекция, **зум кольцом**,
захват RAW (DNG) и экран-«Разведчик» с реальными возможностями всех камер телефона.

Работает на Xiaomi, Samsung и любом Android 11+ — параметры подстраиваются под то,
что конкретная камера отдаёт через публичный Camera2 API.

## Что уже есть
- Живое превью с любой из камер устройства (переключение чипами сверху).
- **Кольцо-зум** справа: крути пальцем — плавно меняется кратность (CONTROL_ZOOM_RATIO).
- Ручная панель (иконка «ползунки»): ISO, Выдержка, Эксп.корр., ББ (K), Фокус —
  у каждого параметра кнопка `A` (авто/ручной).
- **Живая гистограмма** яркости + индикатор пересвета (⚠ %) — экспозиция «как в камере».
- **Стили изображения** (Canon-подобные Picture Styles): Neutral / Standard / Portrait /
  Landscape / Film — честная цветокоррекция (контраст+насыщенность+тёплый сдвиг+тени),
  без нейросетей. **Виден в превью в реальном времени** (OpenGL-шейдер) и применяется к снимку.
- **3D-LUT «плёнки» (.cube)**: встроенные (Тёплая / Винтаж / Тил-оранж) + загрузка своего
  .cube-файла (кино/плёночные LUT). Слайдер силы. Тоже виден в превью (sampler3D в шейдере)
  и применяется к снимку (трилинейная выборка на CPU) — превью и файл совпадают.
- Тумблер **RAW/JPEG**. RAW сохраняется как `.dng` через DngCreator (минует всю обработку).
- Съёмка в `Pictures/NaturalCam` (видно в галерее).
- **Инфо-дисплей в стиле Nikon** (иконка-плитки): экран i-меню с крупными плитками всех
  параметров (Режим P/S/M, Выдержка, ISO, шкала EV, ББ, Фокус AF/MF, Стиль, LUT, Зум,
  Формат, Пикинг/Зебра/Сетка) — тап по плитке меняет параметр.
- **Операторские ассистенты:** фокус-пикинг (подсветка резких краёв), зебра (пересветы),
  сетка по правилу третей, **тап по экрану — точка фокуса/экспозиции**.
- Экран **«Разведчик»** (иконка «i»): по каждой камере — hardware level, есть ли RAW и
  ручной сенсор, диапазоны ISO/выдержки/зума, фокусные, макс. размеры.

## Важно про «Leica» и «без ИИ»
Вычислительную обработку Leica/Xiaomi стороннее приложение получить **не может** — она
внутри штатной камеры. Здесь мы сознательно снимаем «начисто»: JPEG с минимумом обработки
или RAW, а «плёночный» цвет строим сами (LUT/тон-кривые — следующий этап).

## Сборка

### Вариант А — Android Studio (проще всего)
1. Установи **Android Studio** (Ladybug или новее).
2. `File → Open` → выбери папку `naturalcam`.
3. Дождись Gradle Sync (сам скачает SDK/Gradle, создаст local.properties и gradle-wrapper).
4. Подключи телефон по USB, включи **Отладку по USB** (Настройки → Для разработчиков).
5. Нажми ▶ Run. APK соберётся и встанет на телефон.

### Вариант Б — из командной строки
Нужен установленный Android SDK и переменная `ANDROID_HOME`. В папке проекта:
```bash
gradle wrapper        # один раз, если нет gradlew
./gradlew assembleDebug
```
APK будет в `app/build/outputs/apk/debug/app-debug.apk` — поставить:
```bash
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

## Первый запуск
Разреши доступ к камере. Первым делом загляни в **«Разведчик»** — он покажет, какие камеры
твоего Xiaomi 17 Ultra отдают RAW и ручное управление (обычно только главный модуль на
уровне FULL; ширик/теле часто LIMITED без RAW). От этого пляшем в следующих итерациях.

## Архитектура превью
Camera2 пишет кадры в внешнюю OES-текстуру → OpenGL ES 2.0 фрагментный шейдер применяет
стиль (контраст/насыщенность/каналы/тени) → рисует на экран ([GLPreviewRenderer.kt](app/src/main/java/com/denis/naturalcam/GLPreviewRenderer.kt)).
Та же математика в CPU-обработке снимка ([PictureStyleProcessor.kt](app/src/main/java/com/denis/naturalcam/PictureStyleProcessor.kt)) — превью и файл совпадают.
Гистограмма считается из отдельного YUV-потока.

> Ориентация кадра в GL повёрнута на `sensorOrientation`. На конкретном устройстве знак
> поворота/зеркалирование, возможно, потребуют правки — это ожидаемая точка тюнинга.

## Статус
MVP функционально завершён. Основной цикл камеры, ручное управление, цвет (стили + 3D-LUT
в реальном времени), операторские ассистенты и инфо-дисплей — на месте. Осталась доводка
на живом устройстве (ориентация GL, калибровка тап-фокуса) и опциональные улучшения ниже.

## Возможные улучшения потом
1. Захват снимка прямо из GL (FBO readback) — сейчас не нужен: стиль+LUT и так применяются
   к полноразмерному JPEG на CPU (это даже точнее превью — полное разрешение сенсора).
2. Библиотека LUT: папка с .cube, превьюшки, избранное.
3. Брекетинг, таймер, серийная съёмка.
